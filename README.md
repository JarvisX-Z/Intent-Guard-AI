## 🚀 Overview  
**IntentGuard AI** is a next-generation security layer for the Solana ecosystem that verifies whether a transaction matches user intent before execution. It combines blockchain analysis with AI reasoning to detect hidden risks, intent mismatches, and suspicious behaviors—then converts them into simple, human-readable insights.

---

## 🎯 Problem  
Blockchain transactions are complex and often unclear. Users frequently approve actions without understanding their consequences, leading to scams, phishing attacks, and financial loss.

---

## 💡 Solution  
IntentGuard AI ensures that **what users intend to do matches what the transaction actually does**, preventing harmful actions before they occur.

---

## ⚡ Features  
✨ Intent Verification Engine  
🧠 AI Risk Analysis

💬 Human-Readable Explanations  
🛡️ Pre-Transaction Protection
